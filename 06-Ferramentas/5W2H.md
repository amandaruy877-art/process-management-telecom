# 5W2H

## O que é?

O 5W2H é uma ferramenta utilizada para estruturar planos de ação de forma simples e objetiva.

O nome representa sete perguntas fundamentais:

| Sigla | Pergunta |
|--------|-----------|
| What | O que será feito? |
| Why | Por que será feito? |
| Where | Onde será feito? |
| When | Quando será feito? |
| Who | Quem será responsável? |
| How | Como será feito? |
| How Much | Quanto irá custar? |

---

## Quando utilizar

- Planejamento de atividades
- Correção de defeitos
- Melhorias de processo
- Implementação de funcionalidades
- Organização de projetos

---

## Exemplo aplicado ao QA

### Cenário

Foi identificado um defeito crítico no fluxo de login.

| Pergunta | Resposta |
|-----------|-----------|
| What | Corrigir erro no login |
| Why | Usuários não conseguem acessar o sistema |
| Where | API de autenticação |
| When | Sprint atual |
| Who | Desenvolvedor Backend |
| How | Ajustar validação do token |
| How Much | Sem custo adicional |

---

## Benefícios

- Organização
