# 📊 Gestão de Processos - Telecomunicações

## Sobre este projeto

Este repositório foi desenvolvido como um portfólio de estudos sobre **Business Process Management (BPM)**, **Gestão de Processos**, **Melhoria Contínua** e **Consultoria de Processos**, utilizando um cenário voltado ao segmento de Telecomunicações.

O objetivo é documentar conceitos, ferramentas e estudos de caso que fazem parte da rotina de um Consultor de Processos.

---

# Objetivos

- Aprender Business Process Management (BPM)
- Mapear processos corporativos
- Identificar gargalos
- Propor melhorias
- Criar indicadores (KPIs)
- Aplicar metodologias de melhoria contínua
- Desenvolver estudos de caso
- Construir um portfólio profissional
